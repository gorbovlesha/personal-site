# Личное пространство

Персональный сайт: обо мне, проекты, интересы, заметки и контакты. Сейчас это прототип с демонстрационным контентом; он подготовлен для дальнейшей разработки и самостоятельного размещения на VPS.

**Стек:** HTML, CSS, JavaScript без фреймворков. Python используется только для локальных команд и сборки. В production работает Caddy, Python и Node.js там не нужны.

## Быстрый старт

Требования: Python 3.10+. Для полной проверки JavaScript — Node.js 24 (версия в `.nvmrc`). Установка npm-пакетов не требуется.

```bash
python3 scripts/project.py dev
```

Откройте http://127.0.0.1:8080. Изменения видны после обновления страницы. Остановка — Ctrl+C. Другой порт: `python3 scripts/project.py dev --port 3000`.

## Команды

Все команды можно запускать из корня проекта.

| Команда | Назначение |
| --- | --- |
| `python3 scripts/project.py dev` | Локально обслуживать исходники из `src/` |
| `python3 scripts/project.py check` | Проверить структуру, локальные ссылки и JS при наличии Node.js |
| `python3 scripts/project.py check --require-node` | Полная проверка; отсутствие Node.js считается ошибкой |
| `python3 scripts/project.py test` | Регрессионные тесты сборки и проверки путей |
| `python3 scripts/project.py build` | Проверить исходники и пересоздать `dist/` |
| `python3 scripts/project.py build --require-node` | То же, с обязательной проверкой JS |
| `python3 scripts/project.py preview` | Локально посмотреть готовый `dist/` |

`dev` и `preview` по умолчанию слушают только `127.0.0.1`. Это серверы для разработки, для production используется Caddy.

## Структура

```text
src/                        Исходники сайта
  index.html                Разметка и метаданные
  styles.css                Дизайн и адаптивная вёрстка
  content.js                Данные профиля, проектов и заметок
  app.js                    Рендеринг, ссылки и диалоги
automation/                 Серверные роли и очередь Trello
scripts/                    Команды разработки и проверки
  project.py                Dev / check / test / build / preview
  check-content.cjs         Проверка контракта данных
tests/                     Тесты инструментов сборки
docs/                      Архитектура, контент, деплой, план работ
.github/                    CI, шаблоны задач и pull request
Caddyfile                   Production HTTPS и заголовки
compose.yaml                Запуск Caddy на VPS
.env.example                Пример переменных окружения
AGENTS.md                   Правила для coding agents
CONTRIBUTING.md             Порядок разработки
dist/                      Результат сборки, игнорируется Git
```

## Проверки в GitHub

Workflow `Checks` запускается на push в `main` и pull request: проверяет ссылки и структуру контента, синтаксис JavaScript, тесты инструментов, сборку и Caddyfile. Автоматического деплоя нет. Настройте обязательный статус `validate` для слияния в `main` после первого запуска CI.

## VPS

Для текущей статической версии ориентир — **1 vCPU, 1 ГБ RAM и 20 ГБ SSD**. Для других небольших сервисов можно взять 2 ГБ RAM. Бюджет и требования пересматриваются при добавлении CMS, backend или тяжёлых медиа. Подробности запуска — в [инструкции](docs/deployment.md).
