# Карта разделов и прототип

## Назначение и статус

Интерактивный прототип — `src/index.html`. Он показывает путь посетителя от знакомства к примерам работы и способу связаться. Все сведения демонстрационные; личные данные для проектирования структуры не требуются.

Одна страница `/` с пятью разделами. Навигация, порядок блоков и эта карта приведены к одной структуре. В карточке нет подтверждения владельца: структура подготовлена к согласованию, факт внешнего согласования не заявляется. До персонализации нужно подтвердить главное сообщение, названия и порядок разделов, затем предоставить фактический контент и контакты.

## Карта и содержание

| Адрес | Блок | Задача и содержание |
| --- | --- | --- |
| `/` | Первый экран | Пометка «Прототип», имя, краткое сообщение о деятельности и пользе, кнопка «Посмотреть проекты» → `#projects` |
| `/#about` | Обо мне | Краткий рассказ, подход к работе, интересы |
| `/#skills` | Навыки | Три группы с пояснениями, без выдуманных оценок уровня |
| `/#projects` | Проекты | Карточки с описаниями; кнопка открывает подробности в диалоге |
| `/#experience` | Опыт | Последовательность этапов: период, роль, задачи и результат |
| `/#contact` | Контакты | Ссылки для связи; пока явная заглушка без фиктивных адресов |

В шапке — ссылки на все пять разделов. Логотип и ссылка «Наверх» возвращают в начало. Проект открывается поверх страницы, закрывается кнопкой, Escape или нажатием за пределами окна. Ссылка на результат появляется только при заполненном допустимом URL. Отдельные страницы проектов, заметки и блок «Сейчас» в эту версию структуры не входят.

## Схема десктопа, 1440 px

```text
┌─────────────────────────────────────────────────────────┐
│ Логотип     Обо мне  Навыки  Проекты  Опыт  Контакты     │
├─────────────────────────────────────────────────────────┤
│ ПРОТОТИП — сведения демонстрационные                    │
│ Имя + главное сообщение     │ Абстрактная иллюстрация   │
│ [Посмотреть проекты ↓]      │                          │
├─────────────────────────────────────────────────────────┤
│ 01 Обо мне: заголовок       │ Рассказ и интересы        │
├─────────────────────────────────────────────────────────┤
│ 02 Навыки: [Группа 1] [Группа 2] [Группа 3]             │
├─────────────────────────────────────────────────────────┤
│ 03 Проекты: [Карточка] [Карточка] [Карточка]            │
├─────────────────────────────────────────────────────────┤
│ 04 Опыт: период            │ Роль, задачи, результат   │
│          период            │ Роль, задачи, результат   │
├─────────────────────────────────────────────────────────┤
│ 05 Контакты: приглашение   │ Ссылки / заглушка          │
│ Подвал                                        Наверх ↑ │
└─────────────────────────────────────────────────────────┘
```

На 768 px шапка допускает перенос; первый экран и рассказ сохраняют две колонки, навыки и проекты — три. Отступы уменьшаются. Контент определяет высоту блоков, фиксированной высоты текста нет.

## Схема мобильного экрана, 360 px

```text
┌──────────────────────────┐
│ Логотип                  │
│ Обо мне Навыки Проекты    │
│ Опыт Контакты            │
├──────────────────────────┤
│ ПРОТОТИП: примеры данных │
│ Имя                      │
│ Главное сообщение        │
│ [Посмотреть проекты ↓]   │
│ Иллюстрация              │
├──────────────────────────┤
│ 01 Обо мне               │
│ Рассказ, интересы        │
├──────────────────────────┤
│ 02 Навыки                │
│ [Группа 1]               │
│ [Группа 2]               │
│ [Группа 3]               │
├──────────────────────────┤
│ 03 Проекты               │
│ [Карточка 1]             │
│ [Карточка 2]             │
│ [Карточка 3]             │
├──────────────────────────┤
│ 04 Опыт                  │
│ Период → роль и результат│
│ Период → роль и результат│
├──────────────────────────┤
│ 05 Контакты              │
│ Приглашение, заглушка    │
│ Подвал          Наверх ↑ │
└──────────────────────────┘
```

До 650 px блоки переходят в одну колонку. Меню открыто постоянно, без скрывающего разделы переключателя. Область нажатия навигации не ниже 44 px. Порядок чтения и клавиатурного обхода соответствует порядку документа.

## Проверка перед согласованием

Запустить локально командой из README. Проверить на 360, 768 и 1440 px отсутствие горизонтального скролла, переносы меню и карточек. Клавиатурой пройти skip-ссылку, все разделы, открытие проекта, закрытие Escape и возврат фокуса. При reduced motion прокрутка и переходы должны быть без анимации. Схемы выше — проектные артефакты, они не заменяют браузерную проверку.
