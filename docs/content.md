# Контент и персонализация

## Где редактировать

`src/content.js` содержит объект `window.SITE_CONTENT`. Это обычный JavaScript: строки в кавычках, элементы массивов разделены запятыми. После редактирования выполните `python3 scripts/project.py check --require-node`.

| Поле | Содержимое |
| --- | --- |
| `name` | Имя на первом экране |
| `description` | Краткое описание |
| `about` | Первый абзац раздела обо мне |
| `interests` | Массив строк с интересами |
| `projects` | Массив проектов |
| `skills` | Массив групп навыков: `title`, `text` |
| `experience` | Массив этапов опыта: `period`, `title`, `text` |
| `contacts` | Массив контактов; пока пустой |

### Проект

```js
{
  title: 'Название',
  category: 'В разработке',
  visual: 'dashboard',
  description: 'Короткое описание карточки.',
  body: 'Подробная история.\n\nВторой абзац.',
  url: 'https://example.com'
}
```

`visual`: `dashboard`, `map` или `notebook` — три встроенные CSS-иллюстрации. `url` можно оставить пустым или опустить. Остальные поля обязательны и не должны быть пустыми. Для новой иллюстрации обновите CSS, `illustrations` в `app.js` и проверку контракта.

### Навыки и опыт

```js
// Элемент skills
{ title: 'Группа навыков', text: 'Технологии и задачи, подтверждённые практикой.' }
// Элемент experience
{ period: 'Период', title: 'Роль и организация', text: 'Задачи и результат.' }
```

Все поля обязательны, содержат непустые строки. Период пока выводится как текст: реальные даты ещё не предоставлены. Оценки уровня, стаж и работодатели не выдумываются. Порядок элементов соответствует порядку на странице; пустой массив не создаёт карточек.

Проекты открываются в диалоге, отдельной страницы у них пока нет. HTML и Markdown не интерпретируются.

### Контакт

```js
{ label: 'Telegram', url: 'https://t.me/your_username' }
{ label: 'Почта', url: 'mailto:hello@example.com' }
```

Каждый объект — отдельный элемент массива. Поддерживаются абсолютные ссылки `https:`, `http:` и `mailto:`. Для публичных веб-ссылок используйте HTTPS. Пустой массив контактов показывает заглушку.
