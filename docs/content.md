# Контент и персонализация

## Где редактировать

`src/content.js` содержит объект `window.SITE_CONTENT`. Это обычный JavaScript: строки в кавычках, элементы массивов разделены запятыми. После редактирования выполните `python3 scripts/project.py check --require-node`.

| Поле | Содержимое |
| --- | --- |
| `name` | Имя на первом экране |
| `description` | Краткое описание |
| `about` | Первый абзац раздела обо мне |
| `interests` | Массив строк с интересами |
| `professional` | Специализация, стек и опыт; структура ниже |
| `projects` | Массив проектов |
| `now` | Массив текущих занятий |
| `notes` | Массив заметок |
| `contacts` | Массив контактов; пока пустой |

### Профессиональный профиль

```js
professional: {
  specialization: 'Пример специализации',
  summary: 'Кратко о задачах и подходе к работе.',
  stack: ['HTML', 'CSS', 'JavaScript'],
  experience: [
    {
      role: 'Пример роли',
      context: 'Пример проекта или команды',
      period: 'Период будет уточнён',
      description: 'Задачи, личный вклад и результат.'
    }
  ]
}
```

Все строковые поля обязательны и непустые. `stack` — массив строк, `experience` — массив объектов; порядок элементов сохраняется. Опыт выводится списком: располагайте новые этапы первыми. `period` — свободный текст, можно указать диапазон дат или текущую работу. Пустые массивы допустимы, элементы в них не отображаются. HTML в текстах не интерпретируется.

Текущий профиль — мок без реальных компаний, дат и достижений владельца. Пометка `.professional-notice` в `index.html` явно сообщает об этом посетителю. Без JavaScript раздел показывает пояснение о необходимости включить его.

### Проект

```js
{
  title: 'Название',
  category: 'В разработке',
  visual: 'dashboard',
  description: 'Короткое описание карточки.',
  body: 'Подробная история.\n\nВторой абзац.',
  url: 'https://example.com'
}
```

`visual`: `dashboard`, `map` или `notebook` — три встроенные CSS-иллюстрации. `url` можно оставить пустым или опустить. Остальные поля обязательны и не должны быть пустыми. Для новой иллюстрации обновите CSS, `illustrations` в `app.js` и проверку контракта.

### Текущее занятие

```js
{ icon: '↗', label: 'Изучаю', text: 'Что именно сейчас интересно' }
```

### Заметка

```js
{
  date: '10 ноября 2026',
  category: 'Процесс',
  title: 'Заголовок заметки',
  body: 'Текст заметки.\n\nНовый абзац.'
}
```

Текст открывается в диалоге, отдельной страницы у заметки пока нет. HTML и Markdown не интерпретируются.

### Контакт

```js
{ label: 'Telegram', url: 'https://t.me/your_username' }
{ label: 'Почта', url: 'mailto:hello@example.com' }
```

Каждый объект — отдельный элемент массива. Поддерживаются абсолютные ссылки `https:`, `http:` и `mailto:`. Для публичных веб-ссылок используйте HTTPS. Пустой массив контактов показывает заглушку.

- [ ] Заменить демонстрационные имя, интересы, проекты и заметки в `content.js`.

- [ ] Проверить постоянные тексты в `index.html`: второй абзац обо мне, заголовки, первый экран, контакты и подвал.
- [ ] Обновить `<title>`, description и favicon в `index.html`.
- [ ] Удалить `.demo-banner` из HTML и демонстрационные пометки из обработчиков `openDetail` в `app.js`.
- [ ] Обновить подпись `Выбранное / 01—03` при изменении количества проектов.
- [ ] Добавить свои контакты и проверить переходы.
- [ ] Заменить текст-заглушки внутри HTML рядом с динамическими данными: это fallback при недоступном JS.
- [ ] Решить, нужны ли фото, Open Graph-картинка, robots.txt и sitemap.xml для выбранного домена.
- [ ] Проверить мобильную версию, клавиатуру, диалоги и production CSP.

Не добавляйте в этот файл приватные сведения: после деплоя он доступен любому посетителю.
