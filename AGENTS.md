# Работа с проектом

Персональный статический сайт на HTML, CSS и обычном JavaScript. Документация на русском.

- Источник истины — `src/`. `dist/` генерируется и не коммитится.
- Персональные данные и основной контент — `src/content.js`; структура описана в `docs/content.md`.
- Не добавляйте фреймворк, зависимости или backend без конкретной задачи.
- Не выдумывайте реальные факты о владельце. Демонстрационный контент должен оставаться помеченным до персонализации.
- Не добавляйте секреты в `src/`: всё в этой папке будет публично.
- Выводите пользовательские тексты через `textContent`. `innerHTML` допустим только для локальных постоянных иллюстраций.
- Сохраняйте доступность: семантика, видимый focus, клавиатура, Escape в диалогах, reduced motion.
- Не ослабляйте CSP ради inline-скриптов или внешних ресурсов. Конфигурация production — `Caddyfile` и `compose.yaml`.
- Проверки: `python3 scripts/project.py check --require-node`, `python3 scripts/project.py test`, `python3 scripts/project.py build --require-node`.
- Если Node.js или Docker недоступны, явно сообщайте, какие проверки пропущены; успешная Python-проверка не заменяет проверку JS или Caddy.
- Для визуальных изменений проверьте ширины 360, 768 и 1440 px. Когда браузер недоступен, отметьте это в отчёте.
- Обновляйте документацию вместе с изменением команд, структуры данных или деплоя.
